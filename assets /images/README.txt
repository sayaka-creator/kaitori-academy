買取アカデミー｜IDに対応した画像（77モデル）
============================================

■ 各ファイルは、そのIDのカード／クイズ専用の画像です。
   例）id-bag-model-1.webp  → カード f:id-bag-model-1 と クイズ qdk-id-bag-model-1-c4

■ 枚数: 153

■ 入れ方
  1) このZIPを解凍します（id-images フォルダができます）
  2) 中の画像を GitHub の assets /images/ に入れます
  3) commit → push

■ あわせて index.html と JSON を差し替えてください。
